Implementation notes

Phase 4c implementation guidance

Component structure:
  • QueryablesFilterPanel — container with property chips + inline form. Props: queryables, activeFilters, onAddFilter, onRemoveFilter.
  • ActiveFilterChips — renders the blue active filter chips bar. Always visible when filters exist, regardless of panel open/closed state.
  • Filter state: Map<string, string> of propertyName → value. Serialized to URL params: ?status=active&type=tower_mill.
Input types by queryable type:
  • string without enum → text input
  • string with enum → select dropdown
  • number / integer → text input (with inputMode="numeric")
  • boolean → true/false toggle
  • string with format: "date-time" → text input (date picker is a future enhancement)
URL parameter construction:
  • OGC API Features standard: simple property=value query parameters.
  • Multiple filters: ?status=active&type=tower_mill (AND semantics).
  • Parameters are appended to the existing items URL before fetching.
  • Client-side search box text filtering still applies on top of server-side results.
State management:
  • Filter state lives in useItemsFetch hook (same as pagination state).
  • Filter changes reset pagination to page 1.
  • Filters are cleared when collection changes.
  • showFilters toggle state lives in SearchContent (same as collections filter toggle).
