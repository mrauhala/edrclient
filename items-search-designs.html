Behaviour (Records collections — itemType=record):
  • When the collection has itemType=record, the search query is sent to the server using the OGC API Records q parameter (e.g., ?limit=200&q=climate)
  • Query is debounced (300ms) to avoid excessive server requests while typing
  • Results are returned already filtered by the server — no client-side filtering needed
  • Section header reads "Search results" instead of "Matching items" to reflect server-side search
  • Pagination resets to offset=0 when the search query changes
  • For non-record collections (itemType is not record), search remains client-side as before
